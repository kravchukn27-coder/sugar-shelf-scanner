Reading this mockup

applies to

src/app/page.tsx + globals.css

Every element above maps 1:1 to a class already in globals.css — this is a restyle, not a rebuild. No new states, no new interaction logic.

biggest visual delta

Top bar simplification

The live text badge (READY / LIVE / CAPTURED + pulsing dot) is gone from all six screens. If that status is still needed for QA/debugging, it can move to a dev-only overlay instead of shipping UI.

kept on purpose

Per-product overlay boxes

Sugar.no has no multi-object detection screen to borrow from — this is the demo's own invention and its main differentiator, so it stays, just re-skinned to the same glass/radius language as everything else.
