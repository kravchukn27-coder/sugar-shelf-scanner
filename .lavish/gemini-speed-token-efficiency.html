Три Gemini-контракта

01 · Preflight

«Есть ли физическая упаковка?»

Возвращает только candidate, none или uncertain, count, confidence и reasonCode. Не идентифицирует товар, не считает сахар, не возвращает boxes.

Return candidate ONLY when at least one physical, packaged grocery food or beverage is visible and its packaging is sufficiently clear… Return none for people, faces, hands, documents, receipts, screens, loose food and non-food packages.

8 s timeout без retry

02 · Analyze

«Что это за продукты?»

Находит distinct packages, brand/name/pack size, GTIN только если цифры читаемы. Sugar — только визуальная оценка и никогда не считается подтверждённым nutrition.

estimatedSugarPer100g is a visual estimate only; omit it when it cannot be responsibly inferred. confidence reflects visual identification certainty, not nutrition certainty.

30 s + 8 s bounded retry JSON schema

03 · Nutrition label

«Прочитай один label»

Извлекает значения per 100 g и field confidence. Только после пользовательского consent. Нечитаемый снимок возвращает ровно unreadable.

Never invent, estimate, convert, or infer a value. Use null when a field is absent, not legible, or only stated for a serving…

30 s timeout ровно один request/photo

Что уже сделано в speed/token исследовании

DONE

A1/A2 · измерение

Opt-in aggregate telemetry: capture, preflight/analyze RTT, DB probe, catalog resolution, render и preflight attempts. Без image/OCR/GTIN/device data.

DONE

B1–B3 · perceived speed

Progress copy, slow-state reassurance и мягкий uncertain hint.

DONE

D1/D2/D3/D4 · request control

Motion gate, parallel DB probe, client quality gate с bounded fallback и one-shot Details recovery.

DONE

C5 · bounded retry

Один retry только для timeout или 5xx, с отдельным 8-секундным лимитом.

Что ещё не стоит делать вслепую

C2 medium resolution для analyze

Потенциальная экономия токенов, но риск потери мелкого brand/SKU текста. Нужен реальный fixture set.

C3 отдельная preflight model

Сначала подтвердить доступ модели для production API key. Ранее lite-модель дала 404 spike и была откачена.

C4 threshold sweep

Проверить 0.65 / 0.70 / 0.75 / 0.80 на true-candidate и true-none кадрах. Latency telemetry без ground truth недостаточна.

Coverage retry tests

Retry policy реализована, но нужны тесты timeout → retry, 5xx → retry, 4xx/malformed → no retry.
