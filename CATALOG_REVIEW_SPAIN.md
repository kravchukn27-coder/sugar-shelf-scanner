## Curation rules for the seed implementation

- Keep an item's canonical `brand`, `name`, `packSize`, `gtin`, sugar and
  protein exactly as above.  Aliases improve retrieval only; they must never
  bypass the variant and pack-size checks.
- Normalize `33 cl` and `330 ml` to the same volume only.  Do not extend this
  to 250 ml, 335 ml or a 6/9/12/24-pack.
- Corona's Spain-market single-bottle barcode (`8411327013376`) is not
  interchangeable with GTINs assigned to Corona multipacks or other bottle /
  can formats.
- Nutrition for a confirmed response must come from this record, never from
  Gemini.  If the visual candidate identifies only a brand (for example just
  `Schweppes` or `Coca-Cola`), return an estimate/unknown rather than a
  confirmed product.
- Retailer/manufacturer labels can change.  Re-verify this table immediately
  before production import and retain each source URL in provenance.
