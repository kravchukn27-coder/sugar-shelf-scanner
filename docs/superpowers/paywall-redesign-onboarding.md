# Промт №1: подключение и чтение

Отдать другому ИИ **первым**. Копировать всё ниже разделителя.
Второй промт — само задание — он найдёт в репозитории сам, по указанному пути.

---

Ты берёшься за переделку одного экрана в существующем проекте. Сначала
подключись и прочитай контекст. Не пиши код, пока не дойдёшь до конца этого
текста.

## 1. Забери код

```bash
git clone git@github.com:kravchukn27-coder/sugar-shelf-scanner.git
cd sugar-shelf-scanner
npm install
```

Ветка `main`. Нужен Node.js 20.9 или новее.

**Работай в отдельной ветке, не в `main`.** Пуш в `main` немедленно
выкатывает на прод (Railway деплоит на пуш):

```bash
git checkout -b paywall-redesign
```

## 2. Подними локально

Без `.env.local` приложение не стартует. Создай его в корне:

```bash
printf 'VISION_PROVIDER=mock\nNEXT_PUBLIC_PAYWALL_ENABLED=true\nNEXT_PUBLIC_STRIPE_PAYMENT_LINK=https://example.com/placeholder\n' > .env.local
npm run dev
```

`VISION_PROVIDER=mock` отдаёт заранее заданные результаты сканов — ключ Gemini
не нужен и просить его не надо. Ссылка на оплату здесь заглушка: кнопка покупки
должна быть активной, но никуда вести не обязана.

Файл `.env.local` в `.gitignore`. Не коммить его и не вписывай в него ничего
похожего на настоящий ключ.

## 3. Увидь экран, который переделываешь

Сам по себе он не появится: стена показывается только после трёх израсходованных
бесплатных сканов. Подделай это состояние в консоли браузера:

```js
localStorage.setItem("sugar:onboarding-seen:v1","1");
localStorage.setItem("sugar:free-scans:v1","3");
location.reload();
```

После перезагрузки нажми «Start scanning» — вместо камеры откроется пейвол.

**Смотри в мобильном размере 375×812.** Экран нарисован только под телефон;
на десктопе выводы о нём делать бессмысленно. В реальности он почти всегда
открывается во встроенном браузере Instagram на айфоне.

Чтобы вернуться к обычному состоянию:
`localStorage.clear(); location.reload()`

## 4. Прочитай, в этом порядке

1. **`docs/superpowers/paywall-redesign-prompt.md`** — само задание. Там
   позиционирование, фирменный стиль, контракт компонента и список того, что
   обязано остаться на экране. Это главный документ, всё остальное — контекст
   к нему.

2. **`src/app/paywall.tsx`** и **`src/app/paywall.module.css`** — то, что ты
   меняешь. Два файла, больше ничего трогать не нужно.

3. **`src/app/page.tsx`, строка 811** — единственное место, откуда компонент
   вызывается. Посмотри, какие пропсы туда передаются: это контракт, который
   нельзя менять. Сам файл на 900 строк, читать его целиком не нужно — только
   эту строку и её окрестности.

4. **`design/reference/sugar-no-brand-book.html`** — палитра, шкала шрифтов,
   радиусы, семейства кнопок. Открой в браузере, а не читай как текст.
   Обрати внимание: цвет Honey закреплён за платным предложением, а Ember —
   за активной вкладкой. Текущий экран красит кнопку покупки в Ember, и это
   ошибка, которую надо исправить.

5. **`src/app/onboarding-story.tsx`** и **`.module.css`** — единственный
   другой полноэкранный оверлей в приложении. Это образец того, как в этом
   проекте принято такие экраны верстать. Не меняй его, просто посмотри.

6. **`docs/product-ux.md`, раздел «Paid access (monetization test)»** —
   продуктовые правила экрана: почему счётчик оставшихся сканов намеренно не
   показывается, зачем нужно восстановление доступа по почте.

7. **`docs/monetization-test.md`** — зачем вообще этот тест и какие три числа
   он должен принести. Прочитай, если хочешь понимать, почему текст на экране
   важнее его оформления.

## 5. Куда не ходить

Экономь время и не лезь в эти места — они уже написаны, протестированы и
работают на проде:

- `src/lib/access/**` — учёт бесплатных сканов, пропуска доступа, проверка
  оплаты в Stripe.
- `src/app/api/access/**` — маршруты выдачи и восстановления доступа.
- Внутренности сканера в `src/app/page.tsx`: камера, распознавание, результаты.

Если тебе кажется, что задачу нельзя решить без правки этих файлов, — остановись
и скажи об этом, а не меняй их.

## 6. Две ловушки, на которые уже наступали

**Флаги `NEXT_PUBLIC_*` подставляются на сборке.** Поменял значение в
`.env.local` — перезапусти `npm run dev`, иначе в браузере останется старое.

**Не запускай `npm run build`, пока работает `npm run dev`.** Они делят папку
`.next`, и запущенный сервер после этого начинает отдавать 500. Если это уже
случилось: останови сервер, `rm -rf .next`, запусти заново.
